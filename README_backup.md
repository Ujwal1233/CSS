# CSS Selectors Tutorial

A collection of interactive HTML demos showcasing various CSS selectors, pseudo-classes, attributes, descendants, universal selectors, and RGB colors. Perfect for learning core CSS concepts!

## Quick Start

No setup required! Just open any `.html` file in your browser:

```bash
# Example
start index.html
```
